# 전문의약품 총액 계산기

약국 전문의약품의 재고 수량을 입력하면 킴스온라인 보험약가 기준으로 총액을 계산하는 웹앱입니다.

- 재고 입력: 초성·검색으로 약을 찾아 수량 입력, 총액 자동 계산
- 비급여 약: 포장 가격과 규격(개수)을 넣으면 낱개 단가로 계산
- 정보 수정: 품목 이름·킴스 품목명·단가 수정
- 품목 추가·반품: 날짜와 함께 기록
- 기록: 재고조사 결과 저장, CSV 내려받기, 데이터 백업/불러오기

입력한 데이터는 사용하는 기기의 브라우저에 저장됩니다. 다른 기기로 옮길 때는 ‘기록’ 탭의 백업 기능을 쓰세요.

단가 기준일: 2026-11-01 (킴스온라인)
